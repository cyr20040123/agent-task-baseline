● 函数实现完成。总结：

  split_chatml_turns(session: dict) -> list[dict]

  位于 agent_rollout.py:189，独立函数（不在 class 内部）。

  切分规则： 在每个 assistant 消息处切一刀，返回累积前缀 dict。每个输出 dict 包含：
  - messages：从开头到第 n 个 assistant（含）的全部消息
  - tools：完整的 tools 定义
  - 不含 remarks

  示例（上面测试的 4-assistant 场景）：

  输入: sys → user → A1 → user → A2(tool_calls) → tool → A3 → user → A4

  输出 4 个 dict:
    Turn 1: sys, user, A1                                    ← 第一轮问答
    Turn 2: sys, user, A1, user, A2(tool_calls)               ← 工具调用请求
    Turn 3: sys, user, A1, user, A2, tool, A3                 ← 工具调用完成
    Turn 4: sys, user, A1, user, A2, tool, A3, user, A4      ← 完整对话

  这种逐 assistant 切分的方式适合 RL 训练 — 每个 assistant 决策点都是一个训练样本。
